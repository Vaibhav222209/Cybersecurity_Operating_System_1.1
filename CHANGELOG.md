## [1.0.0] — "Kishkindha" — 2026-03-14

### Added
- **Desktop shell**: BIOS/GRUB-style boot log, login & lock screen, top bar (taskbar) with window tabs, left dock, launcher, notification centre, toasts, context menu
- **Power management**: Lock, Log out, Restart, Shut down (animated sequences + power-on screen)
- **Window manager**: drag, 6-direction resize, minimise, maximise, focus & z-order
- **Terminal (`sgsh`)**: 110+ commands, pipes, redirects, `&&`/`;`, globbing, `$VARS`, shell scripts, `sudo`/`su`, tab completion, history, Ctrl+C abort
- **Virtual file system**: Linux-style tree, permissions/ownership, persistence in `localStorage`
- **SIEM Console**: live log stream, severity & source filters, alert triage with response playbooks, MITRE ATT&CK coverage, detection rules
- **Threat Monitor**: animated global attack map, threat gauge, IDS/IPS status, firewall blocklist, IOC feed, auto-response policy
- **VAPT Lab**: scanner (quick/full/stealth), CVE correlation & CVSS, web-app audit, exploit catalogue, Markdown report export
- **System Monitor**: per-core CPU, frequency & temperature, memory, storage, network, process manager, hardware details
- **Crypto Toolkit**, **Files**, **Browser**, **Editor** (Markdown preview), **Settings**, **About**
- 6 accent themes, 3 live wallpapers, CRT scanline option
- GitHub: CI, Pages deploy, release, CodeQL, Dependabot, issue/PR templates, docs
