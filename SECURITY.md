# 🔒 Security Policy

## Scope & nature of the project

**Sugreev OS is an educational simulator.** It does not scan networks, run exploits, store real credentials or contact third-party systems on your behalf. All attack data, CVE findings and logs are generated locally in your browser.

The login password (`sugreev`) is intentionally public and exists only to demonstrate an authentication flow. **Do not reuse it anywhere.**

## Supported versions

| Version | Supported |
|---|---|
| 1.x | ✅ |
| < 1.0 | ❌ |

## Reporting a vulnerability

If you discover a security issue in the application itself (for example XSS, unsafe HTML rendering, or a way for the simulator to reach out to real hosts):

1. **Do not** open a public issue.
2. Use GitHub's private reporting: **Security → Report a vulnerability** on the repository
   (<https://github.com/Vaibhav222209/Sugreev-OS/security/advisories/new>).
3. Include steps to reproduce, affected version and impact.

You can expect an acknowledgement within **72 hours** and a fix or mitigation plan within **14 days** for confirmed issues.

## Responsible use

The terminal and VAPT lab teach real techniques. Please only apply what you learn to systems you **own** or are **explicitly authorised** to test, and follow the laws of your country (for example the IT Act in India, CFAA in the US, Computer Misuse Act in the UK).
